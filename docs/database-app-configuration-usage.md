# 数据库配置使用案例

这里展示两种读取方式：

- `Raindrop.AppConfiguration.Database`：直接执行 SQL，把结果集注入 `IConfiguration`。
- `Raindrop.AppConfiguration.Database.EFCore`：通过 EF Core 查询实体，再映射成业务配置对象。

示例使用 PostgreSQL。SQL 配置源本身只依赖 `IDbConnection`，所以也可以接其他数据库。

## SQL 配置源

先准备表结构：

```sql
create table app_configurations
(
    id integer generated by default as identity primary key,
    app_name text not null,
    max_items integer not null,
    feature_flags jsonb not null
);
```

注册配置源：

```csharp
using Microsoft.Extensions.Configuration;
using Npgsql;
using Raindrop.AppConfiguration.Database;

var configuration = new ConfigurationBuilder()
    .AddDbConfiguration(new DatabaseConfigOptions
    {
        BuildConnection = () => new NpgsqlConnection(
            "Host=localhost;Port=5432;Username=postgres;Password=123456;Database=postgres"),
        Sql = """
            select app_name, max_items, feature_flags
            from app_configurations
            order by id
            """,
        SectionName = "AppConfigurations",
        ReloadOnChange = true,
        ReloadFailureBehavior = ConfigurationLoadFailureBehavior.KeepLastKnownGood
    })
    .Build();
```

数据库列名会按默认规则从 `snake_case` 转成 `PascalCase`，JSON 字段会展开成嵌套配置键，因此可以绑定到普通业务对象。

## EF Core 配置源

需要把数据库实体映射成一个业务配置对象时，用 EF Core 配置源更合适：

```csharp
var configuration = new ConfigurationBuilder()
    .AddEfConfiguration<MyDbContext, AppConfigurationEntity, MyAppOptions>(
        dbContextFactory: () => new MyDbContext(options),
        queryExpression: db => db.AppConfigurations.AsNoTracking().OrderBy(x => x.Id),
        mapper: rows => new MyAppOptions
        {
            AppName = rows.Single().AppName,
            MaxItems = rows.Single().MaxItems
        },
        sectionName: "MyApp")
    .Build();
```

默认异常策略：

- 首次加载失败：抛异常，阻止应用在缺少关键配置时启动。
- 后台刷新失败：保留上一次成功配置，并通过应用接入的 Microsoft.Extensions.Logging 记录异常。
- JSON 解析失败：默认按普通字符串处理；开启严格模式后抛异常。

## 可运行示例

```powershell
dotnet run --project sample\Raindrop.AppConfiguration.Sample -- json
dotnet run --project sample\Raindrop.AppConfiguration.Sample -- database
dotnet run --project sample\Raindrop.AppConfiguration.Sample -- efcore
dotnet run --project sample\Raindrop.AppConfiguration.Sample -- all
```
